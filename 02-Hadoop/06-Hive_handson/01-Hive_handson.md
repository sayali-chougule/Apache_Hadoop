### Step 1: Get a copy of the CSV file

Create a directory named data under project directory by running the following command

```sh
mkdir project_dir/data
```

### Step 2: Change to the data directory

```sh
cd project_dir/data
```

### Step 3: Run the following command to get the emp.csv, a data file with Employee data, in a comma-separated file.

```sh
wget https://cf-courses-data.s3.us.cloud-object-storage.appdomain.cloud/IBM-BD0225EN-SkillsNetwork/data/emp.csv
```

## What is Big data?
Big data refers to extremely large and complex datasets that traditional data processing tools and software cannot easily manage, store, or analyze.

## Small Data VS Big Data 

| Small Data | Big Data |
|---|---|
| Small enough for human inference | Data generated in huge volumes and could be structured, semi-structured, or unstructured |
| Accumulated slowly | Arrives continuously at enormous speed from multiple sources |
| Relatively consistent and structured data usually stored in known forms such as JSON and XML | Needs processing to generate insights for human consumption |
| Mostly located in storage systems within enterprises or data centers | Comprises any form of data including video, photos, and more |
|  | Distributed on the cloud and server farms |
